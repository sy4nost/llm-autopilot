# Проверка догадки «датчик чувствует спор выдумки с фактом» (2026-10-19)

Правило «верна / неверна» записано до подсчёта: PREDICT.md (суммы в sums.txt). Цифры: conflict_out.json.

Ось спора = средний снимок (слой 32) вопросов, где выдумка спорит с фактом, минус средний снимок вопросов, где выдумка совпадает с фактом. Строится без меток «передумала». Для каждого нашего вида задач ось строится по трём другим видам.

| наш вид задач (не видела при построении) | ось спора | датчик | датчик без оси спора | «не уверена» |
|---|---|---|---|---|
| определения D | 0,91 | 0,90 | 0,72 | 0,81 |
| R, привычный ответ верный | 0,96 | 0,97 | 0,76 | 0,69 |
| R, вычислить | 0,69 | 0,69 | 0,61 | 0,88 |
| столицы K | 0,67 | 0,70 | 0,70 | 0,68 |
| ловушки R | 0,61 | 0,80 | 0,81 | 0,52 |
| дорожные слова N | 0,57 | 0,56 | 0,47 | 0,25 |
| среднее | 0,74 | 0,77 | 0,68 | 0,64 |

Вердикт по заранее записанному правилу: ДОГАДКА ПОДТВЕРЖДЕНА (среднее 0,74 ≥ 0,65 и выше «не уверена» 0,64; убрав ось, датчик теряет 0,09 ≥ 0,05).
Но датчик — не только спор: совпадение направлений слабое (около 0,27 из 1), а в ловушках R датчик видит что-то ещё (0,80 без оси спора).

Чужие задачи (ось из всех четырёх наших видов, справочно): MMLU 0,75, отрицание 0,79, unknown 0,69, memo 0,66, pattern 0,65, hindsight 0,54.
«Не уверена» там же: 0,86 / 0,86 / 0,74 / 0,70 / 0,47 / 0,28. То есть на чужих ось спора в основном слабее простой неуверенности.
Средний уровень оси на чужих ловушках низкий, как у наших «выдумка совпадает с фактом»: в чужих задачах такого спора почти нет.
