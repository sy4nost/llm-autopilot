# Pre-registered plan: "lamp → louder new rule" on unfamiliar tasks

*English translation. The original text, frozen before the run, is in the git history (commit 6d3f172). The checksums below are of the code and data files, not of this text.*

Written 2026-10-17, before Alex named the random number and before any run on the real tasks.
After Alex names the number, this file and the scripts do not change. File checksums are at the end.

## What we test

The recipe found on "rule with conditions" tasks, without a single adjustment:
1. **Lamp.** The model answers twice: as usual (normal) and with old examples fully muted in the 40 copying heads (w0, heads b40 from eras/settings2.json, found on the old tasks). The lamp fires if the answer changed or its lead over the second option fell below half of the normal one.
2. **If it fires**, take the answer where the change line is 16 times louder in all layers (up16_all), from the question onward. If it does not fire, take the normal answer.

## Model and tasks

- Model Qwen2.5-14B-Instruct, the same intervention code as in eras/modal_boost.py (modal_new.py).
- Two new task types (make_new.py), not used before:
  - **robot:** command words mean actions; the change alters the meaning of one word.
  - **points:** colored chips are worth points, the answer is the sum; the change alters the value of one color.
- 20 sets per type. Each has 4 test cases: 2 "traps" (the change concerns the case) and 2 "untouched".
- Arms: A60, E_copy, E_nocopy, N_same, N60, R60 (note "checked, everything as before"), F0 (ceiling). Described in make_new.py.
- Tasks are generated by the script from the number Alex will name. Before the run check_new.py must show 0 problems.

## Success criteria (for each task type separately)

- **Gain:** traps in A60 + E_nocopy. Correct answers "by lamp" minus normal: at least +10 points, and the lower bound of the 95% interval (bootstrap over sets) above 0.
- **No harm:** where experience is right, i.e. untouched cases in A60/E_nocopy/E_copy plus all cases in N60, R60, N_same. Change in correct answers no worse than −5 points.
- **PASS** only if both criteria are met on both types. Otherwise FAIL, and I report it as is.
- **Report only, not for the verdict:** E_copy traps, "always ×16", "always mute", the ×4 variant, ceiling F0.

## Technical trial run

Before this plan there was one trial run on 28 tasks with another number (12345). It checked only the mechanics: w1 and up1 identical to normal, and the boundaries of text pieces. Its answers do not go into conclusions.
